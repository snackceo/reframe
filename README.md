# Reframe

**See information the way it works for you.**

Reframe is an accessibility-oriented information representation layer for mobile reading.

The core idea is to let the reader choose how information is represented while keeping the underlying source available.

Examples:

- Highlight nouns, verbs, dates, names, or key phrases.
- Break dense content into sentences.
- Turn a paragraph into a list.
- Organize information as Who / What / When / Where / Why / How.
- Expose relationships and structure without requiring the reader to decode everything from continuous prose.
- Provide multimodal representations such as audio where appropriate.

## Project status

**Concept / prototype stage.**

The product interaction and representation model are still being explored. Platform, model, and implementation choices are intentionally not locked.

## Core principle

> **The reader chooses the representation; Reframe does the work of creating it.**

Reframe should change how information is presented without silently changing what the source says.
